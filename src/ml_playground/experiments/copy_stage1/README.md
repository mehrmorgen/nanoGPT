Minimal Stage 1 curriculum experiment: learn deterministic identity mapping over two symbols (`A/B`) without collapsing to a constant output.

## Overview

- Dataset: synthetic deterministic two-symbol stream generated by the experiment preparer from `prepare.raw_text_path`.
- Tokenization: character-level.
- Method: tiny GPT-style next-token prediction on CPU-safe defaults.
- Pipeline: `prepare`, `train`, `sample` via runtime CLI.

## Data

- Input source: `prepare.raw_text_path` (defaults to `datasets/input.txt`). The preparer reads the file, expects exactly two unique non-whitespace characters, and emits a balanced deterministic alternating sequence.
- Prepared artifacts:
  - `train.bin`
  - `val.bin`
  - `meta.pkl`

## How to Run

- Config: `src/ml_playground/experiments/copy_stage1/config.toml`

Prepare:

```bash
uv run cli --exp-config src/ml_playground/experiments/copy_stage1/config.toml prepare copy_stage1
```

Train:

```bash
uv run cli --exp-config src/ml_playground/experiments/copy_stage1/config.toml train copy_stage1
```

Sample:

```bash
uv run cli --exp-config src/ml_playground/experiments/copy_stage1/config.toml sample copy_stage1
```

## Outputs

- Data artifacts: `src/ml_playground/experiments/copy_stage1/datasets/`
- Training and sampling artifacts: `src/ml_playground/experiments/copy_stage1/out/copy_stage1/`
