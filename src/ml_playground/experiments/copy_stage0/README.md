Minimal Stage 0 curriculum experiment: learn deterministic identity mapping on a single symbol (`A -> A`) through the standard `prepare -> train -> sample` pipeline.

## Overview

- Dataset: synthetic deterministic one-symbol stream generated by the preparer.
- Tokenization: character-level.
- Method: tiny GPT-style next-token prediction on CPU-safe defaults.
- Pipeline: `prepare`, `train`, `sample` via runtime CLI.

## Data

- Input source: bundled deterministic seed at `datasets/input.txt` (no network dependency).
- Prepared artifacts:
  - `train.bin`
  - `val.bin`
  - `meta.pkl`

## How to Run

- Config: `src/ml_playground/experiments/copy_stage0/config.toml`

Prepare:

```bash
uv run cli --exp-config src/ml_playground/experiments/copy_stage0/config.toml prepare copy_stage0
```

Train:

```bash
uv run cli --exp-config src/ml_playground/experiments/copy_stage0/config.toml train copy_stage0
```

Sample:

```bash
uv run cli --exp-config src/ml_playground/experiments/copy_stage0/config.toml sample copy_stage0
```

## Outputs

- Data artifacts: `src/ml_playground/experiments/copy_stage0/datasets/`
- Training and sampling artifacts: `src/ml_playground/experiments/copy_stage0/out/copy_stage0/`
