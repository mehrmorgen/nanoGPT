# Self-Play Utilities

## Purpose

Self-play helpers for replay policies, outcome filters, and gate counters.

## Structure

- `utilities.py` - Replay policies, outcome filtering, gate counts, and metric emitters

## Key APIs

- `Outcome`, `ReplayPolicy`, `OutcomeFilter`
- `GateCounts`, `accumulate_outcomes`
- `gate_metrics()`, `emit_gate_metrics()`
